Install AkuBrowser Runtime

This installs the AkuBrowser Native Messaging Host and universal runtime for the current macOS user. Google Chrome remains responsible for the AkuBrowser extension.

Security notice: this stable package is not Developer ID-signed or notarized. macOS may block the first install. Continue only if you downloaded it from the official AkuBrowser GitHub release and verified its published SHA-256 checksum.

Do not disable Gatekeeper globally. After attempting to open this package, use System Settings > Privacy & Security > Open Anyway if you accept the unsigned package risk.

Your AkuBrowser data is preserved during install, repair, and update.
