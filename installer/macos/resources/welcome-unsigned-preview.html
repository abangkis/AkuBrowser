Install AkuBrowser Runtime Early Preview

This installs the AkuBrowser Native Messaging Host and universal runtime for the current macOS user. Google Chrome remains responsible for the AkuBrowser extension.

Early Preview security notice: this package is not Developer ID-signed or notarized. macOS may block the first install. Only continue if you downloaded it from the official abangkis/AkuBrowser GitHub release and verified its published SHA-256 checksum.

Do not disable Gatekeeper globally. After attempting to open this package, use System Settings > Privacy & Security > Open Anyway if you accept the preview risk.

Your AkuBrowser data is preserved during install, repair, and update. If Installer detects a downgrade, it archives data written by the newer runtime and creates a fresh database for the older runtime.
