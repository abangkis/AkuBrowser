# AkuBrowser v0.9.0 RC7

Windows x64 prerelease candidate built from the clean source commits below. The installer retains application version 0.9.0 under the existing RC packaging convention.

## Change since RC6

- The native **AkuBrowser startup** recovery window now appears for a fresh isolated browser profile or a changed installed source tuple, not on every everyday launch. Once the interface sends a valid ready acknowledgement, that profile records the tuple fingerprint and subsequent launches of the same build stay quiet. Development launches also do not show the native status window.
- The interface-ready handshake remains active even when the native window is hidden. On the first launch after a new installation or update, the status window still offers **Retry window**, diagnostics, and the prior manual recovery path. A missing or unreadable marker fails open to recovery. The marker contains no browser session or startup capability.

## Distribution and known limits

The installer contains AkuBrowserLauncher, AkuSidecar, the production-app AkuBridge payload, pinned Chromium, c2patool, configuration, and checksums. Verify the accompanying SHA-256 before running it. The installer is **unsigned**; code signing, whole-tuple automatic rollback, and independent clean-machine certification remain open hardening work.

The first-launch white-window cause is **not fixed or established** by this change. The native Retry path was accepted in an earlier local fresh-profile run, but this RC7 installer has not yet received live visual acceptance. Four installation/onboarding acceptance items remain open: INST-01 (real installer-upgrade database handling), INST-02 (first-launch white window and post-onboarding Chrome-banner acceptance), INST-03 (uninterrupted first-run journey through Grant access), and INST-05 (real Gemini key/project/quota validation). INST-04 (isolated-profile login continuity) is complete in the selected scope. Codex App/App Server remains an external prerequisite; Gemini is an optional user-configured provider.
