# AkuBrowser v0.9.0 RC2

Status: **Windows x64 prerelease candidate**. RC2 is rebuilt from the latest
clean AkuBrowser, AkuBridge, and AkuSidecar source tuple. The installer remains
intentionally unsigned, so Windows may show a SmartScreen warning. Verify the
published SHA-256 before running it.

## What changed since RC1

- Personal Memory now powers Library recall and source-backed Related Context.
- Related Context uses one post-anchored drawer, follows the active reading
  context, accepts relevance feedback, and sizes itself against the full post.
- Living Topics can route confirmed non-duplicate Timeline evidence, maintain
  current understanding, expose new-evidence badges, move evidence between
  topics, and contribute knowledge to Library search and Related Context.
- Library search can retrieve retained memory and Living Topics knowledge from
  one bounded local search surface.
- Gallery fit and zoom actions are snap points while manual zoom remains
  available.
- The installed database boundary is schema 22 with additive migration support
  from schemas 7 through 21.

## Distribution and limitations

RC2 contains one complete installed-app tuple: AkuBrowserLauncher, AkuSidecar,
the internal `production-app` AkuBridge payload, pinned Chromium, c2patool,
configuration, manifests, and checksums. It does not require system Chrome,
Developer Mode, or manual extension loading.

Code signing, whole-tuple automatic rollback, and independent clean-machine
certification remain open hardening work. Codex App/App Server remains an
external prerequisite; Gemini remains an optional user-configured provider.
