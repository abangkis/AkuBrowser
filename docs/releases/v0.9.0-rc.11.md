# AkuBrowser v0.9.0-rc.11

RC11 is a Windows x64 installed-app candidate for the existing `0.9.0`
product line. The installer remains `AkuBrowserSetup-0.9.0-windows-x64.exe`;
the candidate suffix identifies the release, rather than changing the product
version or the installed-app channel. The installer is unsigned.

## Changes since RC10

- Bounded headless collection freshness recovery and shared source adapter
  behavior, including native-page fallback for unresolved video.
- Stronger media identity and poster validation for X and Instagram, including
  exclusion of videos belonging to quoted or reposted X posts in legacy data.
- Related Context v6 requires a concrete issue owned by the same subject.
  Ordinary prose cannot admit or rank an automatic suggestion. Complete model
  identities, percentage and duration parsing, broad Library search, and
  existing feedback history are preserved.
- Clearer manual-window-close guidance and reader/batch resume recovery.
- Pinned packaged headless Node worker and bounded build output retention.
- Release checks exclude disposable diagnostic fixtures, reuse configured Go
  caches, and verify recapture cleanup against its admitted runtime generation.

## Build and verification

Run `scripts/check.ps1`, then `scripts/build-windows-installed-app.ps1`
with output under `artifacts/rc11/tuple`, followed by
`scripts/build-windows-installed-app-installer.ps1` and
`scripts/test-windows-installed-app-installer.ps1`. The installer and its
checksum are under `artifacts/rc11/installer`.

Quote-ownership regressions and Related Context matcher, Store/FTS, and API
tests passed before packaging. Packaging validation checks the source tuple,
Bridge identity, pinned runtimes, payload integrity, and launcher verification;
it does not prove successful playback of every captured video.

## Remaining acceptance boundaries

Clean-machine installation, upgrade over RC10 with preserved data/profile,
and authenticated source collection on the installed RC11 were not performed;
the user deferred these checks for this candidate. Request explicit confirmation
before running installation and related manual acceptance in the future.
Database rollback is not implemented. The artifact build does not install or
restart the development runtime. GitHub publication uses the frozen artifact
tuple; this later documentation update does not change its source identity.
