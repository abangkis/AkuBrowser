# AkuBrowser 0.8.0

AkuBrowser 0.8.0 expands source coverage and makes continuous local feed
processing more adaptive and resilient.

Highlights:

- adds Instagram capture and native inline video playback;
- improves inline video evidence and recovery for X, LinkedIn, and Facebook;
- adds adaptive scheduling, content-runway pacing, and idle standby;
- separates AkuSidecar compatibility and signed runtime-update feeds from the
  browser release cadence;
- hardens setup, Store identity, native-host readiness, repair, and lifecycle
  handling; and
- streamlines reproducible Windows and macOS release kits and acceptance gates.

Release acceptance:

- Windows automated acceptance and clean-machine acceptance: passed;
- macOS automated and clean-machine acceptance: pending;
- companion installers remain intentionally unsigned and may show Windows
  SmartScreen, antivirus, or macOS Gatekeeper warnings.

This release remains a draft until both platform artifact sets, checksums,
manifests, SBOMs, and clean-machine evidence have been reconciled.
