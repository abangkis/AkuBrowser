# Chrome Web Store submission checklist

## Package

- [ ] Manifest name and listing name are `AkuBrowser`.
- [ ] Version matches the release tuple.
- [ ] Manifest V3 ZIP is generated by the checked-in builder.
- [ ] ZIP contains every imported/registered script and no test, native
      executable, source map, key, dependency tree, or remote code.
- [ ] 16, 32, 48, and 128 px icons pass dimension checks.

## Store listing

- [ ] Indonesian primary listing copied from `listing/id-ID.md`.
- [ ] English listing copied from `listing/en-US.md`.
- [ ] Category is Productivity.
- [ ] At least one current 1280x800 screenshot uploaded.
- [ ] Homepage, support, and privacy URLs resolve publicly.
- [ ] Companion-runtime requirement is prominent.

## Privacy

- [ ] Single purpose matches `privacy-declarations.json`.
- [ ] Website content, web history, user activity, and displayed identity data
      are declared.
- [ ] OpenAI/Codex processing is declared.
- [ ] Limited Use certification matches `PRIVACY.md`.
- [ ] No sale, advertising, or remote-code claims match the package.
- [ ] Prominent in-product disclosure and affirmative per-source consent tested.

## Permissions

- [ ] Required permissions copied from `permission-justification.md`.
- [ ] Social hosts remain optional and independently revocable.
- [ ] No unused permission appears in the uploaded manifest.

## Reviewer and release gate

- [ ] Reviewer instructions copied to the dashboard.
- [ ] Signed companion installer stable URL returns the production executable.
- [ ] Signed runtime manifest and versioned ZIP exist on the matching release.
- [ ] Installer host pins the public key matching the offline update-signing key.
- [ ] Prior supported signed release upgrades successfully and rollback evidence
      has been captured.
- [ ] Native host contains the exact Store extension ID.
- [ ] Stage 5 clean-machine evidence is complete.
- [ ] Submission uses deferred publishing for the first review.
