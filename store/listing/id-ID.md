# AkuBrowser

## Ringkasan singkat

Bangun feed AI pribadi dari X, LinkedIn, dan Facebook yang Anda izinkan.

## Deskripsi

AkuBrowser membantu Anda mengubah feed sosial yang padat menjadi timeline AI
pribadi yang lebih relevan.

Anda memilih sendiri sumber yang boleh dibaca. Halaman setup pada awalnya
menyarankan X, LinkedIn, dan Facebook, tetapi tidak ada izin domain sosial yang
diberikan sampai Anda mengonfirmasi pilihan dan menyetujui permintaan izin
Chrome. AkuBrowser hanya membaca konten yang dirender pada sumber yang Anda
aktifkan.

Fitur utama:

- menangkap feed secara read-only dan terbatas;
- menyusun item ke timeline lokal;
- mendeteksi duplikasi dan hubungan antarperistiwa;
- mempelajari preferensi dari feedback eksplisit Anda;
- menampilkan bukti sumber dan tautan posting asli;
- memberi kontrol retensi dan reset data lokal.

AkuBrowser memerlukan companion runtime yang dipasang terpisah pada Windows
atau macOS. Setup hanya menautkan artifact tetap dari rilis GitHub resmi
AkuBrowser. Installer Early Preview Windows masih dapat memicu peringatan
Windows Security atau antivirus. Paket macOS `v0.7.9-preview1` tidak
ditandatangani dan tidak dinotarisasi, sehingga Gatekeeper dapat memblokir saat
pertama dibuka; Setup meminta pengguna memverifikasi SHA-256 yang dipublikasikan
dan memakai **Privacy & Security > Open Anyway**, tidak pernah menonaktifkan
Gatekeeper. Instalasi Linux belum tersedia pada 0.7.9. Runtime menyimpan data
produk di perangkat Anda. Fitur AI dapat mengirim
konten terpilih ke OpenAI melalui Codex App yang Anda gunakan.

AkuBrowser tidak meminta password atau cookie sosial, tidak menjual data, tidak
memakai data untuk iklan, dan tidak memuat JavaScript jarak jauh.
