# Trust Regression Contract v0

> Status: **Deterministic boundary fixtures implemented**
> Date: **2026-07-12**

## Purpose

Trust boundaries must be executable regression tests rather than prompt prose alone. The suite verifies that untrusted source instructions stay inside the delimited browser-observation payload, the acquisition planner retains its narrow authority statement, reasoning evidence is bounded and deduplicated, and presentation-only media is absent from text-model input.

Operational diagnostics must not expose the absolute database path, bridge token, or permissive cross-origin headers. SQLite backup paths are escaped and verified through temporary-database tests. Existing extension permission, source-media host, provenance, and account-mutation regressions remain mandatory.

These tests do not claim that a model can never be manipulated. They verify the deterministic isolation, validation, and least-authority layers around the model and browser adapters.
